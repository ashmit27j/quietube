# Changelog

## [0.1.0] — unreleased
Scaffold. Registry, CSS engine, storage/mode resolution, popup, options page,
service worker, docs, skills and commands. Behaviour handlers are written but
not yet verified against live YouTube — see docs/ROADMAP.md v0.2.

### Added
- 41 toggles across 9 groups, generated from a single registry
- Modes (Off / Casual / Music / Study / Custom) with per-feature overrides
- Scheduled mode switching, and Peek (30s reveal, `Alt+Shift+P`)
- Shorts URL redirect to the standard player
- Synchronous no-flash CSS path (localStorage-mirrored flags)
- Options page and popup, both generated from the registry
- Icons, generated by `tools/gen-icons.py`
- Offline test suite: registry consistency, storage/mode resolution, CSS engine
  against synthetic fixtures, and a real unpacked-extension load in Chromium
- CI workflow, release gate (`tools/check-release.mjs`)

### Fixed
- `grayscale_thumbs` hid thumbnails instead of desaturating them: the feature
  matched both the generic hide loop and its own filter rule. Introduced
  `style: true` (decision D12).
- Comments and the home placeholder ran before YouTube had hydrated them;
  handlers now wait for their target via a bounded, self-disconnecting observer
  (`src/lib/dom.js`).
- Shorts redirect could trap the Back button; it now uses `replace()` plus a
  sessionStorage guard and preserves the `t` timestamp parameter.
